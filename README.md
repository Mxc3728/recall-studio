# Recall Studio

Recall Studio is a small installable study app. Paste material, mark words or phrases to hide, then switch to Study mode and tap hidden chunks to check yourself.

## Use On A Phone

To install it like an app, the folder needs to be served from a secure web link. GitHub Pages, Netlify, and Vercel all work.

On iPhone:

1. Open the web link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.

On Android:

1. Open the web link in Chrome.
2. Tap the install prompt if it appears, or open the menu.
3. Tap Install app or Add to Home screen.

After it is opened once from the web link, the app shell is cached for offline use. Your study material is saved on that device.
